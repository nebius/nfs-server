Shared storage.
Ready for Kubernetes.

An NFS server Docker image and Helm chart to deploy shared storage in your cluster.

Helm chart Docker image amd64 + arm64

Install with Helm

Add the repository, then install the latest chart. Helm and access to a Kubernetes cluster are required.

# Add the chart repository
helm repo add nebius-nfs https://nebius.github.io/nfs-server/
helm repo update

# Install or upgrade the NFS server
helm upgrade --install nfs-server nebius-nfs/nfs-server
